## Rules

- 프로젝트별 기획, 아이디어, 승인, 결정과 버전 기록은 각 프로젝트 루트 안에서 관리한다.
- 새 프로젝트를 만들 때 기존 프로젝트의 작업 파일을 재사용하거나 섞지 않는다.
- 사용자가 프로젝트를 명시하지 않았고 등록 프로젝트가 여러 개라면 작업 전에 대상 프로젝트를 확인한다.
