# Intake Workflow

## Compatibility Notice

최상위 요청 분류는 자동으로 읽히는 `AGENTS.md`의 `Request Routing`이
소유한다. 이 문서는 기존 링크를 깨지 않기 위한 호환 진입점이며 별도의 intent
목록이나 하위 절차를 정의하지 않는다.

1. `AGENTS.md`의 요청 유형 표에서 상세 원본을 하나 선택한다.
2. 프로젝트 작업이면 `docs/workflows/project_workspace.md`로 프로젝트를 먼저
   확정한다.
3. 문서 변경 요청이면 `docs/workflows/document_change.md`로 이동한다.
4. 검색·설명 요청은 파일을 수정하지 않는다.
